## Game Hub — Steam Stable
For the regular Steam client. Recommended configuration for standard users **after validation**. Planned Windows filename: `GameHub-Steam-Stable.zip`.

## Game Hub — Steam Beta
Compatibility configuration for the November 18, 2026 CSS changes. **Awaiting separate Beta tester evidence and acceptance.** Planned Windows filename: `GameHub-Steam-Beta.zip`.

Check Steam > Settings > Interface > Client Beta Participation and record the version shown under About Steam. Changing channel is not required for existing users. Do not switch the working production machine for this investigation.

Keep OS and Steam channel separate when selecting a package. SteamOS/Bazzite remain experimental and need their own OS-bound builds/testers. No automatic update may move Stable users to Beta. Keep Direct Updater automatic installation off.

Before an approved install: back up the plugin and settings outside the plugin directory, close games/calls/downloads, select the matching OS and Steam channel ZIP in Decky, and keep the existing Game Base Social identity. Do not install two variants simultaneously. Roll back using the backed-up matching package and unchanged settings; use native Steam recovery if Game Hub cannot initialize.

Release is blocked on real Stable/Beta testing, the launch-return investigation, remaining selector review, and baseline lint failures. No publication or deployment without the owner's explicit approval.
