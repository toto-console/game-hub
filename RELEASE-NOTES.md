# Game Hub 0.13.0-dev.38

Experimental Windows-first pre-release. Download `Game-Hub-0.13.0-dev.38-decky.zip` (not GitHub's automatic source archives). Compare its SHA-256 against `SHA256SUMS.txt`.

Includes PS5-inspired Home, Welcome widgets, Library, Control Center, Game News, social features and media shortcuts, plus the new release discovery and verified-download settings. Original UI/features are retained.

Windows 11 x64 is the local development/load-check environment. Windows 10, SteamOS LCD/OLED and Bazzite are untested. No universal compatibility claim. Windows Store/Friend Activity presentation and ThemeDeck bridge have platform/version restrictions. Steam internal API changes can affect navigation and integrations. Audio and live Xbox acceptance are user-tested after this release.

Automatic installation is disabled. Update checks and downloads cannot restart Steam or replace files in the installed plugin. Use Decky's **Install Plugin from ZIP** while idle after backing up Game Hub and its settings. See README for install, settings preservation, recovery and experimental-platform details. No games, saves, Steam credentials, music packs or personal artwork are included.

Validation results are in UPDATE-VALIDATION.md and the linked GitHub Actions run. Manual interruption recovery, first-time Linux installation, gameplay and voice-call tests have not been performed. Optional integrations require separately installed compatible plugins; a custom ThemeDeck bridge is not installed automatically.
